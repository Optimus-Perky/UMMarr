API

build {{.Version}}

JSON under /api/v3, shaped like Radarr and Sonarr's. Send the API key from Settings → General as the X-Api-Key header or ?apikey=; a signed-in browser session works too. Ids are UMMarr's; tmdbId / foreignArtistId / foreignAlbumId are the provider's.

MethodPathWhat it does
Movies
GET/api/v3/movieEvery movie
GET/api/v3/movie/{id}One movie with its file
GET/api/v3/movie/lookup?term=Search TMDB
POST/api/v3/movie{"tmdbId", "rootFolderId"?, "qualityProfileId"?, "monitored"?, "searchForMovie"?}
PUT/api/v3/movie/{id}{"monitored"}
DELETE/api/v3/movie/{id}?deleteFiles=trueRemove, optionally with its folder
TV
GET/api/v3/seriesEvery series
GET/api/v3/series/{id}One series with its seasons
GET/api/v3/series/lookup?term=Search TMDB
POST/api/v3/series{"tmdbId", "rootFolderId"?, "qualityProfileId"?, "monitored"?}
PUT/api/v3/series/{id}{"monitored"?, "seasons": [{"seasonNumber", "monitored"}]?}
DELETE/api/v3/series/{id}?deleteFiles=trueRemove, optionally with its folder
GET/api/v3/episode?seriesId=A series' episodes
PUT/api/v3/episode/{id}{"monitored"}
Music
GET/api/v3/artistEvery artist
GET/api/v3/artist/lookup?term=Search MusicBrainz
POST/api/v3/artist{"foreignArtistId", "rootFolderId"?, "qualityProfileId"?}
GET/api/v3/albumEvery album
GET/api/v3/album/{id}One album with its tracks
POST/api/v3/album{"foreignAlbumId", "artistId"}
PUT/api/v3/album/{id}{"monitored"}
DELETE/api/v3/album/{id}?deleteFiles=trueRemove, optionally with its folder
Activity & settings

GET/api/v3/qualityprofileQuality profiles with their items
GET/api/v3/rootfolderLibrary folders
GET/api/v3/downloadclientDownload clients (no secrets)
GET/POST/PUT/DELETE/api/v3/indexer, /indexer/schema, /indexer/testIndexers, as Prowlarr's Radarr sync uses them
