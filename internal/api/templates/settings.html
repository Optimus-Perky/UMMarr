Naming guide

How templates work

  • Type any text you like. Each {Token} is swapped for that item's value. Spell token names exactly as listed below, capitals included.
  • A token with no value comes out blank, and so does a misspelled one. {Movie Title} ({Release Year}) gives Title () for a movie whose year isn't known.
  • Numbered tokens can be zero-padded by adding zeros: {season:00} turns 1 into 01, and {episode:000} turns 5 into 005.
  • In a folder box, / starts a subfolder: Various Artists/{Series Name} makes one folder inside another. In a file name box it's removed or replaced like the other characters below.
  • {{.CharacterRule}} Spaces and dots at the end of a name are trimmed.
  • With renaming turned off for a media type, files keep their own names and its file name box isn't used.
  • Saving never renames or moves anything already on disk.
  • The movie, series, artist, album and Various Artists series folder boxes only apply to things you add afterwards. Downloads for things already in your library keep going into their existing folders.
  • The season folder and file name boxes apply to every download from then on, including new episodes and tracks for things you already have.
